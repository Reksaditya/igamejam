DEADLINE - BUILD WINDOWS x86_64

Ekstrak seluruh isi ZIP, kemudian jalankan Deadline.exe.
Deadline.pck dan folder pendukung harus tetap berada bersama Deadline.exe.

New Game meminta nama pemain. Load melanjutkan autosave terakhir.
A/D atau panah kiri/kanan: berjalan.
Shift: berlari.
E: interaksi, memasuki pintu, duduk atau berdiri dari kursi.
Spasi: QTE saat belajar atau merakit.
Klik profil di kanan atas untuk status, jurnal, dan pengaturan.
Pengaturan menyediakan volume dan pilihan resolusi.

Kamar pemain: Asrama, lantai 2, kamar 210.
Komputer dan tempat tidur di kamar dapat diakses melalui interaksi E.

Save dan pengaturan tersimpan di %APPDATA%\Godot\app_userdata\Deadline.
Build ini masih memakai aset dummy pada sejumlah lokasi dan objek.

Dibuat menggunakan Godot Engine. Informasi lisensi Godot dan komponen
bawaannya: https://godotengine.org/license/
Lisensi addon disertakan di folder licenses.
